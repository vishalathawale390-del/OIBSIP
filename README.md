## 📂 Project Portfolio

This internship track offers five Data Science projects. The task folders below will contain the corresponding notebooks, datasets or dataset instructions, visualizations, and documentation.

### 🌸 Task 1 — Iris Flower Classification

**Objective:** Predict the species of an iris flower from its physical measurements.

**Key Features**
- Dataset exploration and statistical summaries.
- Pair plots and feature-wise box plots.
- Feature selection and train-test splitting.
- Training and comparison of at least two classification algorithms.
- Confusion matrices, accuracy, precision, recall, and F1-score.

**Skills Demonstrated:** Classification, EDA, Feature Selection, Model Evaluation.

📁 Folder: `DataScience-Task1-IrisClassification/`

---

### 📉 Task 2 — Unemployment Analysis with Python

**Objective:** Analyze unemployment trends across Indian states and investigate changes around the COVID-19 pandemic.

**Key Features**
- Data cleaning and preprocessing.
- State-wise and month-wise unemployment analysis.
- Time-series visualizations.
- Top 10 states by average unemployment rate.
- Correlation heatmap and pre-COVID versus post-COVID comparison.

**Skills Demonstrated:** Data Analysis, Time-Series Visualization, Statistical Interpretation.

📁 Folder: `DataScience-Task2-UnemploymentAnalysis/`

---

### 🚗 Task 3 — Car Price Prediction with Machine Learning

**Objective:** Predict used-car selling prices using relevant vehicle attributes.

**Key Features**
- Missing-value handling and duplicate removal.
- Feature engineering, including car age and brand extraction.
- Exploratory analysis of selling prices, fuel types, and vehicle age.
- Categorical encoding and correlation analysis.
- Comparison of at least two regression models.
- MAE, RMSE, R² evaluation and feature importance visualization.

**Skills Demonstrated:** Regression, Feature Engineering, Data Cleaning, Predictive Modelling.

📁 Folder: `DataScience-Task3-CarPricePrediction/`

---

### 📧 Task 4 — Email Spam Detection with Machine Learning

**Objective:** Classify messages as spam or legitimate (ham) using Natural Language Processing.

**Key Features**
- Text preprocessing and class distribution analysis.
- TF-IDF feature extraction.
- Training and comparison of at least two classification models.
- Confusion matrix and classification metrics.
- Analysis of precision, recall, and false-negative errors.

**Skills Demonstrated:** NLP, Text Classification, TF-IDF, Machine Learning.

📁 Folder: `DataScience-Task4-SpamDetection/`

---

### 📈 Task 5 — Sales Prediction Using Python

**Objective:** Predict product sales based on advertising expenditure across TV, radio, and newspaper channels.

**Key Features**
- Dataset inspection and exploratory analysis.
- Pair plots, scatter plots, and correlation heatmap.
- Linear Regression baseline and an additional regression model.
- MAE, RMSE, and R² evaluation.
- Residual analysis and advertising-channel impact interpretation.

**Skills Demonstrated:** Regression, Business Analytics, Data Visualization, Model Interpretation.

📁 Folder: `DataScience-Task5-SalesPrediction/`

## ⚙️ Installation & Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/vishalathawale390-del/OIBSIP.git
```

### 2. Navigate to the Repository

```bash
cd OIBSIP
```

### 3. Install the Required Libraries

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

For Task 4, additional packages may be required:

```bash
pip install nltk wordcloud
```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open the notebook inside the relevant project folder and run the cells in order.

**Note:** Some tasks require external datasets. Follow the dataset instructions in the relevant project folder before running the notebook.
